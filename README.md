# RubberToe's Field Of View Manager
## 📃Description
You wanted to see even more? (Or less, but let's be honest... who really wants that?)

This mod changes the default FOV range from 50–90 to 20–170. Now you can see civilians running into your gunfire even sooner!

Want to see more (or less) of your character's muscles? (SOON) you'll be able to see even more of your guns!

My friends and I wanted this mod, but since it hadn't been updated for UE5 yet, I took matters into my own hands and made it myself.

If only my friends had a higher FOV, they would've seen it coming.

## ⚙️ How to install
* Install UE4SS (Dependencies are listed on [the instructions tab of the modpage](https://modworkshop.net/mod/58641?tab=instructions)
* Drop the extracted folder in `\PAYDAY3\Binaries\Win64\UE4SS\Mods`
